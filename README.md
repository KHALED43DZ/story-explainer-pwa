# استوديو القصص بالدارجة (PWA) — v2.0
1. ارفع كل محتويات المجلد إلى جذر مستودع GitHub (مع الملف المخفي `.nojekyll`).
2. Settings ← Pages ← Deploy from a branch ← main / root.
3. افتح الرابط، ثم ⚙️ الإعدادات وأضف مفتاح Gemini (كل مفتاح في سطر).
4. «قصة جديدة في الاستوديو»: ① الفكرة ← ② البرومبتات ورفع الصور ← ③ الفيديو التفاعلي.
- الصور تولّدها بنفسك في تطبيق Gemini ثم ترفعها من المعرض.
- «لدي صورة قصة جاهزة» يبقى متاحًا في الرئيسية للنمط القديم.
- لتغيير الأيقونة: tools/icon-maker.html ثم غيّر الرقم في sw.js.
